# Anisakan Coffee & Tea Garden Resort (React SPA)

A modern React single-page application rewritten with TypeScript, Vite, and full multilingual support (English, Myanmar, Simplified Chinese). Showcases the Anisakan Coffee & Tea Garden Resort located near Aung Chan Thar Village in Pyin Oo Lwin, Myanmar.

## Features

- **Interactive 360° Estate Explorer**: Interactive vector terrain map with zone pins (`01 Farming`, `02 Factory`, `03 Relax`), tabbed exploration, highlight tags, and curated activity lists.
- **The Art of the Washed Process**: Interactive 6-stage coffee production guide (Flotation Tank & Sizing, Mechanical Depulping, Tank Fermentation, Raised Sun-Drying, Hulling & Density Grading, Artisan Roasting & Nitrogen Sealing) with step navigation, progress tracking, and key craftsmanship facts.
- **The Orchard**: Interactive companion crops gallery (Tea, Dragon Fruit, Passion Fruit, Macadamia, Banana & Papaya) with interactive hover and tap expansion cards.
- **Project Proposal & Presentation**: Proposal preview, download triggers, and dedicated full-screen presentation mode for guest meetings and investors.
- **Interactive Trip Planner**:
  - 3 signature experiences: Day Harvest Tour, Weekend Villa Stay, and Specialty Cupping Workshop.
  - Interactive guest count selector (1–12 guests).
  - Real-time illustrative MMK estimate calculations and customized itinerary breakdown.
  - "Enquire about this trip" quick-action: pre-fills the enquiry message with trip details, party size, and estimated cost, and smoothly scrolls to the enquiry form.
- **Dual-Mode Enquiry System**:
  - Vacation & Day Trip Booking (with preferred dates & phone).
  - B2B Green Coffee & Wholesale Supply (with company name & volume requirements).
  - Automatically generates pre-addressed, formatted `mailto:` drafts to `umyohtut1971@gmail.com`.
- **Complete Multilingual Support (i18n)**:
  - Supports English (`en`), Myanmar (`my` - မြန်မာ), and Simplified Chinese (`zh` - 中文).
  - Language-tailored typography and line heights for Myanmar (`Noto Sans Myanmar`) and Chinese (`Noto Sans SC`).

## Development

```bash
# Start Vite development server on port 3000
npm run dev

# Compile TypeScript and build for production
npm run build

# Run TypeScript type check
npm run lint
```
